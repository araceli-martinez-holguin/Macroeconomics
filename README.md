# Graduate Macroeconomics — Master in Economics - School of Economics - UNAM

Welcome to the repository for the **Macroeconomics** graduate course offered as part of the **Master in Economics** program at the **School of Economics**. 

This repository contains the computational scripts, problem set solutions, and quantitative models used throughout the course.

---

## 📌 Repository Contents

- **Numerical Methods & Simulations:** Implementation of key macroeconomic models (e.g., Solow, Ramsey–Cass–Koopmans, Real Business Cycle, New Keynesian).
- **Data Analysis & Econometrics:** Scripts for processing time-series data, filter applications (Hodrick-Prescott, Hamilton), and VAR models.
- **Problem Sets & Assignments:** Code and replication materials for coursework.
